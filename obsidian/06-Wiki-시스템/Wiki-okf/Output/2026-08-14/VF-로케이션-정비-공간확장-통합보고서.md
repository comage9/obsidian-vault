## 1. 배경 및 감사 리스크

### 1.1 감사 기준
- 지정된 VF 로케이션 안에는 **해당 로케이션 지정 품목과 수량만** 보관
- **원칙: 1개 로케이션 = 지정된 1개 품목만** 보관  
  (예: 1번 로케이션 → ‘오더 오크 화이트 모던 플러스’만)

### 1.2 운영팀 브리핑 (전일 약 20:30–21:30, 1시간)
- 지정 공간 = 지정 품목 + 수량 일치 **필수** 강조
- **다음 달 랜덤 업체 지정 감사** 예고
- 미준수 시 **VF 계약 해지 가능** 명시
- 현재 계약 공간 내 완제품 점유 ≈ **403품목** → 나머지 위치 확보·공간 확장 필요

### 1.3 초과 재고 처리 원칙 (이번 달 내 완료)
| 단계 | 내용 |
|:-----|:-----|
| (a) | 로케이션 한도 초과분 → **임시 로케이션** 이동 |
| (b) | 임시 이동 시 **전산 입고 잡지 않음**. 기존 자리 여유 시 복귀 정리 |
| (c) | **이번 달 내** 전량 완료 |

## 3. 공간 부족 및 확장

- 지정 VF 로케이션 공간 절대 부족
- **대응 방향:** 기존 VF 구역 외 **바깥·야외 공간까지 VF 구역 확장** → 로케이션 추가
- **블로커:** 야외 공간이 **추가 계약 공간으로 지정**되어야 함 (미지정 시 외부 배치 실행 불가)

### 추가 공간 필요 품목군
- 양쪽 창고 적재·제품 보관 중인 **벌크**
- **칵투스** 계열

---

## 4. 공간 확보 방안 (현장 운영안)

### 4.1 파레트 → 수작업·개별 적재 (점유 축소)
- **슬림 서랍장** 일부: 그레이 6단, 아이보리 5단, 6단·5단·4단, 4단 아이보리 등  
  → 파레트 단위 적재가 아닌 **손/개별 적재**로 공간 축소
- 전반적으로 **출고 수량 적은 제품**도 팔레트 대신 **개별 적재**

### 4.2 출고 감소 품목 → 바깥 + 다품목 연결
- **와이드 서랍장** 등 출고 줄어든 품목 → 바깥쪽 공간 활용
- 한 파레트에 **2품목**, 소형은 **3품목**까지 연결·일렬 나열
- **모던 플러스** 중 출고 적은 품목도 동일 방식 적용 가능

### 4.3 출고 많은 순 정리
- 전체적으로 **출고가 많은 순**으로 로케이션·적재 정리
- 저출고 품목은 개별 적재로 공간 확보

## 5. 현재 실행 계획 (확정 방향)

전산 재고 수량 페이지 품목 ∩ 제품 마스터 관리 품목 기준.

| 순서 | 계획 | 비고 |
|:----:|:-----|:-----|
| **1** | 「**VF 3개월 출고 없음**」(VF 3개월 미출고) 해당 품목 → **VF가 아닌 FC로 우선 전환** | 전산 상태 옵션 활용 |
| **2** | VF 출고 진행 계획 중 **상위 순** 재배치 → **파레트 단위** 자리 배치 | 고출고 우선 |
| **3** | 그 외 제품 → **한 파레트에 여러 종류** 제품 적재 형태로 자리 배치 | 다품종 파레트 |

## 6. 미결 사항

### 6.1 미출고·잔여 재고 처리
출고되지 않고 남아 있는 재고도 **위치 확보 + 적재** 대상이므로 결정 필요.

| 선택 | 내용 |
|:-----|:-----|
| **(A) 반출** | 해당 재고를 모두 반출 |
| **(B) 보관 유지** | 그대로 보관하면서 공간을 확보해 자리 마련 |

- 실행 계획 1단계(VF 3개월 미출고 → FC 전환)와 **병행·연계** 검토
- 참고 수치: 미출고 **102** + 무고정 출고 **370**

### 6.2 야외 추가 계약
- 바깥·야외 배치·확장의 **전제 조건** — 추가 계약 공간 지정 협의 필요
