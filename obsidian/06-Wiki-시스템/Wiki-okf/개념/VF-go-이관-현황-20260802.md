## 프로토콜

- **handoff-tasks**: START_HERE → CURRENT_TASK → 소단위 문서
- 한 세션 = 한 소단위, "다음" 전 다음 Task 금지
- DB = `vf_go_dev`만 사용
- 스키마 → DB → domain → HTTP → 패리티 5단계
