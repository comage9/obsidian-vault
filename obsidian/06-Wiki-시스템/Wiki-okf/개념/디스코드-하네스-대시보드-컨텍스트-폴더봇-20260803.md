# 디스코드 하네스 멀티 에이전트 — 대시보드·컨텍스트 관리·작업 폴더 봇

> 영상: AI 치트키 (v40AFadpg4w, 11:07) — 확인일 2026-08-03. 저장만, 검토 대기.

## 배경 구조 (지난 영상 v1)

**하네스 멀티 에이전트:** AI 1개를 지휘자(오케스트레이터)로 세우고 일꾼(워커)들을 부리는 구조. 디스코드 작업 채널에 할 일 한 줄 → 지휘자 봇이 계획+배치 올림 → 사용자 "승인" → 일꾼 봇(클로드·코덱스·제미나이)이 각자 결과 올림. 별도 API 비용 없음(구독 그대로).

## 추가된 3가지

### ① 대시보드 채널 (usage-coach)
- 클로드·코덱스·안티그래비티 남은 사용량 막대 (초록=여유, 노랑=절반, 빨강=1/4 이하)
- **코칭 문구**: "지금 큰 작업 돌려도 되는지"까지 대신 판단 — 핵심 기능
- 봇별 상태: 작업 폴더·모델·컨텍스트 사용량 (제미나이는 값 파일 미저장이라 불가)
- 구현: 5분마다 **웹훅 메시지 1개를 계속 고쳐 씀** → 채널에 글 항상 1개 = 항상 현재 상태
- 알림은 상태 악화 전환 시에만 (초록→노랑→빨강)
- 실패담: PNG 그림 → 디스코드 축소로 폰에서 깨알 → **글자 기반(Components V2)** 재작성

### ② 컨텍스트 관리 (원격 세션 교체)
- 채팅 한 줄 "세션 마감하고 새로 시작해" → 마감 전 **작업 기록 파일에 오늘 한 일 저장** → 새 세션 기동(1초 내) → 파일 읽고 이어감
- **세션은 새것, 기억은 파일로** — 컨텍스트 16%→6% 리셋 확인 가능

### ③ 작업 폴더 봇 (folder-bot)
- 아무 작업 폴더나 전용 디스코드 채널 봇으로 승격. **채널 1 = 폴더 1 = 세션 1**
- 설치 3단계: 클로드 코드 실행 → 마켓플레이스+플러그인 설치(명령 2줄) → 대화로 등록 (토큰·채널 ID는 개발자 포털에서 선 생성)
- claude·codex 엔진 지원, 새 봇은 대시보드 자동 등재

### 부가 개선
- 재부팅 시 봇 동시 기동 미연결 → **순차 연결(한 번에 하나씩)** 로 수정
