# VF 제품배치도 총괄 뷰 + B동·C동 레이아웃 (2026-08-16)

## 작업 내용
1. **총괄 배치도(개요) 탭 추가**
   - A~E동 5개 동이 한 화면에 미니 배치로 표시
   - 각 동 카드 클릭 → 해당 동 상세 뷰로 이동
2. **B동 블록 레이아웃** (이미지 기준, 42칸)
   - B상단(8) / B우측(5) / B중앙1(6) / B중앙2(8) / B좌측(4) / B하단1(4) / B하단2(7)
   - zone id: `B-B상단-1` 형식
3. **C동 블록 레이아웃** (이미지 기준, 16칸)
   - C중앙(8) / C우측(8)
   - zone id: `C-C중앙-1` 형식
4. **툴팁 최근 출고 수량** (직전 작업)
   - 최근 3개월 일평균 4일치 + 최근 1개월 30% 가중
   - `(avg90 + avg30×1.3) / 2 × 4` 반올림
   - barcode-daily API(90일) fetch

## 기술
- `buildBlockLayout(dong, blocks)` 함수 신설: 블록형 배치 공용
- `DongKey`에 `"ALL"` 추가, 탭에 "총괄" 버튼
- 총괄 뷰: 좌표 0.18배 축소 미니 배치

- D동/E동은 "라인 배치 대기" 상태 (레이아웃 미정)
