# 제품배치도 시프트 버그 수정 + 검색 정렬 (2026-08-19)

## 배경
사용자가 A동에서 "19,28" 한 칸 배치를 시도하던 중:
1. **1-16이 빈칸으로 남고 뒤로 밀리지 않음**
2. **제품 1번(1-1)이 2-18로 이동**

## 근본 원인 (코드 확인)
| 버그 | 원인 |
|------|------|
| 시프트 순서 역순 | `aSeq`가 `buildADongLayout` 빌드 순서(line 내림차순 L6→L1) 그대로 → 시프트가 엉뚱한 칸으로 밀림. 1-19에 L7 제품값이 유입되는 현상 확인 |
| 칸 비우기 시 밀림 없음 | `applyPlacementEdit`에서 `dupZones.size === 0`이면 즉시 return → 빈칸이 생겨도 뒤에서 당겨지지 않음 |

## 수정 (Claude Code 위임, product-display.tsx만)
1. **aSeq 물리 순서 정렬**: `cmpZoneOrderA` 추가 (L1-1→L1-19→L2-1→…→L6-19→L7-{col}-{row}→X1→X2), 기존 zoneOrderA와 단일화
2. **applyPlacementEdit 빈칸 메우기**: `emptied` Set 도입 — 칸 비우기(zid, A동) + 중복 제거 칸을 시작점으로 뒤 칸들을 앞으로 당기고 맨 끝만 비움. zid 값 보존, B/C/D동 보호
3. **검색 정확 일치 우선 정렬**: `searchResults`에 rankOf(정확=0/접두=1/기타=2) + numCmp + placed 우선 정렬 → "28" 검색 시 28이 맨 위
