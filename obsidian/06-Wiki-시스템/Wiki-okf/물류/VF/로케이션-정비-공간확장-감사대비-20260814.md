# 보노하우스 VF 로케이션 정비 및 공간 확장 계획 (감사 대비)

> 출처: 사용자 전달 보고서 + 전일 운영팀 구두 브리핑 (2026-08-14 세션 기록)
> 원본: [[Sources/텍스트/2026-08-14_보노하우스-VF-로케이션-정비-공간확장-보고]]

## 요약

- **목적:** 오더 지시 감사(Audit) 대비 + 공간 부족 해소
- **마감:** 이번 달 내 로케이션 정비 완료
- **리스크:** 다음 달 랜덤 감사 미준수 시 **VF 계약 해지 가능**
- **핵심 갭:** 출고 품목 773개 중 고정 로케이션 **403개만** 지정 (약 370개 무고정)

## 1. 감사 대비 로케이션 정비

### 원칙
- **1 로케이션 = 1 지정 품목만** 보관
- 지정 로케이션 안에는 **해당 품목·해당 수량만** 보관 (운영팀 강조)

### 초과 재고 처리
| 단계 | 내용 |
|:-----|:-----|
| (a) | 로케이션 한도 초과분 → **임시 로케이션**으로 이동 (예: 80개 중 40박스 초과) |
| (b) | 임시 이동 시 **전산 입고 잡지 않음**. 기존 로케이션 여유 생기면 복귀 정리 |
| (c) | **이번 달 내** 전량 완료 |

## 2. 공간 부족 및 확장

- 지정 VF 로케이션 공간 절대 부족
- **대응:** 기존 VF 구역 외 **바깥 외부 공간까지 VF 구역 확장** → 로케이션 추가 확보
- 계약 공간 내 완제품 점유 품목 ≈ **403개** → 나머지 위치 확보 + 확장 필수

## 3. 품목·로케이션 현황 (보고 수치)

| 구분 | 수량 | 비고 |
|:-----|-----:|:-----|
| 전체 관리 품목 | 875 | |
| 실질 출고 품목 | 773 | |
| 미출고 (3개월 무출고) | 102 | 재고는 있으나 최근 3개월 출고 이력 없음 |
| 로케이션 지정됨 | **403** | 출고 773 중 |
| 고정 자리 없음 | **370** | 출고 요청 시 임시 포장 출고 (비효율) |

- 미출고 102를 배치 대상에서 제외해도, 출고 품목 전량 수용에 **현재 로케이션 절대 부족**

## 4. 운영팀 브리핑 (전일, 약 20:30–21:30 / 1시간)

1. 지정 공간 = 지정 품목 + 수량 일치 **필수**
2. **다음 달 랜덤 업체 지정 감사** 예고
3. 미준수 시 **VF 계약 해지** 가능 명시
4. 403품목 외 나머지 위치 확보·공간 확장 필요성 재확인

## 5. 후속 과제 (상태: 진행중)

- [ ] 이번 달 내 1:1 로케이션 정비 + 초과분 임시 로케이션 이동 (전산 미입고 유지 규칙 준수)
- [ ] 외부 공간 VF 구역 확장 협의·로케이션 추가
- [ ] 370개 무고정 출고 품목 우선순위 배치 (3개월 미출고 102는 배치 후순위 가능)
- [ ] 감사 체크리스트: 지정 로케이션 품목·수량 일치 현장 검증
