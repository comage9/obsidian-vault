# 보노하우스 VF 로케이션 정비 및 공간 확장 계획 (감사 대비)

> 출처: 사용자 전달 보고서 + 전일 운영팀 구두 브리핑 (2026-08-14 세션 기록)
> 원본: [[Sources/텍스트/2026-08-14_보노하우스-VF-로케이션-정비-공간확장-보고]]

## 요약

- **목적:** 오더 지시 감사(Audit) 대비 + 공간 부족 해소
- **마감:** 이번 달 내 로케이션 정비 완료
- **리스크:** 다음 달 랜덤 감사 미준수 시 **VF 계약 해지 가능**
- **핵심 갭:** 출고 품목 773개 중 고정 로케이션 **403개만** 지정 (약 370개 무고정)
- **공간 확보:** 슬림 서랍장 파레트→수작업 적재 · 와이드/저출고 모던플러스 2~3품목 연결 바깥 배치 · 출고 많은 순 정리+저출고 개별 적재 · **야외 추가계약 필수** · 벌크·칵투스 공간 필요
- **실행 계획:** ① VF 3개월 미출고 → **FC 우선 전환** ② VF 출고 상위 순 파레트 재배치 ③ 그 외 다품종 파레트
- **미결:** 미출고·잔여 재고 — **반출(A)** vs **보관 유지+자리 확보(B)** (FC 전환과 병행)

## 1. 감사 대비 로케이션 정비

### 원칙
- **1 로케이션 = 1 지정 품목만** 보관
- 지정 로케이션 안에는 **해당 품목·해당 수량만** 보관 (운영팀 강조)

### 초과 재고 처리
| 단계 | 내용 |
|:-----|:-----|
| (a) | 로케이션 한도 초과분 → **임시 로케이션**으로 이동 (예: 80개 중 40박스 초과) |
| (b) | 임시 이동 시 **전산 입고 잡지 않음**. 기존 로케이션 여유 생기면 복귀 정리 |
| (c) | **이번 달 내** 전량 완료 |

## 2. 공간 부족 및 확장

- 지정 VF 로케이션 공간 절대 부족
- **대응:** 기존 VF 구역 외 **바깥 외부 공간까지 VF 구역 확장** → 로케이션 추가 확보
- 계약 공간 내 완제품 점유 품목 ≈ **403개** → 나머지 위치 확보 + 확장 필수

## 3. 품목·로케이션 현황 (보고 수치)

| 구분 | 수량 | 비고 |
|:-----|-----:|:-----|
| 전체 관리 품목 | 875 | |
| 실질 출고 품목 | 773 | |
| 미출고 (3개월 무출고) | 102 | 재고는 있으나 최근 3개월 출고 이력 없음 |
| 로케이션 지정됨 | **403** | 출고 773 중 |
| 고정 자리 없음 | **370** | 출고 요청 시 임시 포장 출고 (비효율) |

- 미출고 102를 배치 대상에서 제외해도, 출고 품목 전량 수용에 **현재 로케이션 절대 부족**

## 4. 운영팀 브리핑 (전일, 약 20:30–21:30 / 1시간)

1. 지정 공간 = 지정 품목 + 수량 일치 **필수**
2. **다음 달 랜덤 업체 지정 감사** 예고
3. 미준수 시 **VF 계약 해지** 가능 명시
4. 403품목 외 나머지 위치 확보·공간 확장 필요성 재확인

## 5. 공간 확보 방안 (2026-08-14 추가)

### 5.1 파레트 → 수작업 적재 (점유 축소)
| 대상 예시 | 변경 |
|:----------|:-----|
| 슬림 서랍장 그레이 6단 | 파레트 적재 → **손 적재** |
| 슬림 서랍장 아이보리 5단 | 동일 |
| 슬림 서랍장 6단·5단·4단 | 동일 |
| 슬림 서랍장 4단 아이보리 | 동일 |

### 5.2 출고 감소 품목 → 바깥 + 다품목 연결
- **대상 예:** 와이드 서랍장 등 출고 줄어든 품목
- **방식:** 한 파레트에 **2품목**, 소형은 **3품목**까지 연결·일렬 나열 → 최소 적재 공간 확보
- **모던 플러스:** 출고 적은 품목도 동일 방식으로 일부 공간 확보 가능

### 5.3 블로커 — 야외 추가 계약
- 바깥/야외 공간 활용의 **전제:** 야외 공간이 **추가 계약 공간으로 지정**되어야 함
- 미지정 시 외부 확장·바깥 배치 계획 실행 불가

### 5.4 추가 공간 필요 품목군
- 양쪽 창고 적재·제품 보관 중인 **벌크** 형태
- **칵투스** 계열 제품

### 5.5 출고 많은 순 정리 + 저출고 개별 적재
- **전체:** 출고가 많은 순으로 로케이션·적재 정리
- **출고 수량 적은 제품:** 팔레트가 아닌 **개별 적재**로 공간 확보

### 5.6 최종 쟁점 — 미출고·잔여 재고 (결정 필요)
- **문제:** 출고되지 않고 남아 있는 재고도 **위치 확보 + 적재** 대상
- **미결 결정:**
  - **(A) 반출:** 해당 재고를 모두 반출
  - **(B) 보관 유지:** 그대로 보관하면서 공간을 확보해 자리 마련
- 보고 수치 참고: 미출고(3개월 무출고) **102품목** + 무고정 출고 **370** 등과 연계

### 5.7 현재 실행 계획 (전산 재고·제품 마스터 기준)
| 순서 | 내용 |
|:----:|:-----|
| 1 | 전산 재고 수량 페이지 품목 ∩ 제품 마스터 중 **「VF 3개월 출고 없음」(VF 3개월 미출고)** → **VF → FC 우선 전환** |
| 2 | VF 출고 진행 계획 **상위 순** 재배치 → **파레트 단위** 자리 배치 |
| 3 | 그 외 제품 → **한 파레트에 다품종** 적재 형태로 자리 배치 |

## 6. 후속 과제 (상태: 진행중)

- [ ] 이번 달 내 1:1 로케이션 정비 + 초과분 임시 로케이션 이동 (전산 미입고 유지 규칙 준수)
- [ ] **야외 공간 추가 계약 지정** 협의 (외부 확장 전제)
- [ ] 슬림 서랍장 계열 파레트→수작업 적재 전환 실행
- [ ] 와이드·저출고 모던플러스: 2~3품목 연결 바깥 배치
- [ ] 출고 많은 순 정리 + 저출고 개별 적재 적용
- [ ] **「VF 3개월 출고 없음」품목 VF→FC 우선 전환** (전산 재고·제품 마스터)
- [ ] VF 출고 상위 순 파레트 단위 재배치 + 그 외 다품종 파레트 배치
- [ ] **미출고·잔여 재고: 반출(A) vs 보관 유지+자리 확보(B) 결정** (FC 전환과 병행 검토)
- [ ] 벌크·칵투스 계열 공간 배정
- [ ] 370개 무고정 출고 품목 우선순위 배치 (3개월 미출고 102는 배치 후순위 가능 — 단 B 선택 시 자리 필수)
- [ ] 감사 체크리스트: 지정 로케이션 품목·수량 일치 현장 검증
