# 제품배치도 미배치 통합 + 위치 검색 (2026-08-16)

## 배경
- 총괄 뷰 미배치 패널이 `A_UNPLACED`(A동 기준, 715건)를 그대로 사용
- B동에 배치된 제품 101건이 미배치에 섞여 표시 → "배치됐는데 미배치에 뜨는" 문제
- 사용자 요구: ①통합적으로 볼 것 ②배치된 제품은 미배치에서 제외 ③제품명/로케이션/제품번호/바코드로 위치 확인 검색창

## 변경 내용 (frontend/client/src/pages/product-display.tsx)
1. **통합 미배치 계산**: `placedPnums` = `data`(A동 순위 + B동 + 사용자 배정) 전체의 제품번호 집합
   - `unplaced = A_UNPLACED.filter(!placedPnums.has)` → A_UNPLACED 715 − B동 배치 101 = **614건**
   - 총괄 미배치 패널·헤더 카운트·A동 하단 테이블 전부 통합 기준으로 교체
2. **위치 검색창 추가** (헤더 아래, Search 아이콘 + Input):
   - 검색 대상: 배치된 제품(`data`→pnum/이름/바코드/로케이션) + 미배치 제품(`unplaced`)
   - 로케이션 문자열: `pnumToLoc()` — 320-A1-1-N / 2XXX → 320-A1-2-XX 규칙
   - 결과: `제품번호 · 제품명` + `위치 X동 zone` (배치) / `미배치 · 로케이션 loc`
   - 클릭 시: 배치 → 해당 동 탭 전환 + 슬롯 amber ring 하이라이트, 미배치 → 총괄+미배치 패널+상세
3. 배치 내역 상세 패널의 A_UNPLACED 참조를 unplaced로 교체
