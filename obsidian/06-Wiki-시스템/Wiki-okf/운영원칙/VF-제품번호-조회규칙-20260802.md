# VF 제품 번호 조회 규칙

## 제품 번호 정의

**제품 번호 = 로케이션(location)에서 파생된 숫자**

| 로케이션 패턴 | 제품 번호 | 예시 |
|--------------|-----------|------|
| `320-A1-1-XXX` | XXX | 320-A1-1-164 → **164** |
| `320-A1-2-XX` | 2XX | 320-A1-2-14 → **214** |
| `320-A1-2-XXX` | 2XXX | 320-A1-2-173 → **2173** |

규칙: 세그먼트가 `2`로 시작하면 앞자리 `2`를 붙인다.

## 동일 로케이션 복수 품목

**하나의 로케이션에 바코드가 2개 이상일 수 있음.**

예: 150번 (320-A1-1-150)
- R006596970003 — 로코스 수납 바스켓 L 4개 화이트
- R012319330004 — 로코스 수납 바스켓 L 라이트 화이트 4개

**조회 시:** 로케이션으로 검색 → 해당 바코드 전부 출고 조회 → 합산 보고.

## 조회 방법

**API:** `GET http://127.0.0.1:5176/api/master/specs`

### 제품명 → 번호
사용자가 제품명(또는 약칭)을 말하면 아래 필드 **모두** 검색:
- `product_name` (한글 제품명)
- `category_lg` (대분류 — 사용자 약칭인 경우 많음)
- `category_md` (중분류)
- `color1` (색상 코드)

**주의:** 사용자 약칭 ≠ product_name인 경우 많음.
- "탑백" → category_lg = "탑백 리빙박스"
- "로코스" → category_lg = "리빙박스 로코스"
- "야채바구니" → category_lg = "야채바구니"

### 번호 → 제품명
로케이션 필드에서 역산:
- `164` → location 끝이 `-164` 또는 `-2-164`
- `2173` → location `320-A1-2-173`

## 응답 형식

제품 번호 질문 시:
```
{제품명} = {번호}번 (로케이션: {location}, 바코드: {barcode})
```

번호 질문 시:
```
{번호}번 = {제품명} (로케이션: {location}, 바코드: {barcode})
```
